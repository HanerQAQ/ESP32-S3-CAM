## Reporting a Vulnerability

If you discover a security vulnerability related to Wi-Fi provisioning, Web API endpoints, I²C/UART frame parsing, or buffer handling:

1. **Do not disclose the issue publicly** in public GitHub Issues or discussions.
2. Submit your report via GitHub **Private Vulnerability Reporting** (Security Advisories) or contact `@HanerQAQ` with:
   - Affected component(s) and description of the vulnerability.
   - Reproduction steps or proof-of-concept details.
   - Potential impact and suggested mitigation.

We will acknowledge receipt within 48 hours and work with you to resolve confirmed issues promptly.

### 安全漏洞提报

如果您在 Wi-Fi 配网、Web API 接口、I²C/串口帧解析或内存缓冲处理中发现潜在安全漏洞：

1. **请勿在公开的 GitHub Issues 或讨论区披露漏洞细节**。
2. 请通过 GitHub **Private Vulnerability Reporting（私密安全通告）** 提交或联系 `@HanerQAQ`，并在报告中包含：
   - 受影响组件及漏洞描述；
   - 复现步骤或 PoC 说明；
   - 潜在影响评估与修复建议。

维护者将在 48 小时内响应确认，并尽快协同修复。
