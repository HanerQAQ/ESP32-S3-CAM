# ESP32_S3_CAM Arduino Library

Arduino I2C master driver library for the **ESP32-S3-CAM** Offline Vision and Streaming Module.

## Installation
Drop this folder into `Arduino/libraries/ESP32_S3_CAM` or import via Arduino IDE's **Sketch -> Include Library -> Add .ZIP Library...**.

## Examples
See `File -> Examples -> ESP32_S3_CAM`:
- `01_cat_dog_detect`
- `02_color_detect`
- `03_face_detect`
- `04_face_recognition`
- `05_image_transmission`
- `06_qrcode`
